2. TRANSFORMATIONS CSS APPLIQUÉES

IMAGE HERO:
  • height: 100vh → 0 (ou transform: scaleY(1.0) → scaleY(0.0))
  • opacity: 1.0 → 0.0 (optionnel)
  • RECOMMANDÉ: transform: scaleY() pour GPU performance

CONTENU:
  • transform: translateY(0) → translateY(-100vh)
  • Synchronisé avec disparition image
  • will-change: transform (GPU optimization)

═══════════════════════════════════════════════════════════════════════════════

3. FORMULES JAVASCRIPT

// 1. Pourcentage de scroll
   scrollPercent = min(scrollY / (heroHeight * 0.5), 1.0)

// 2. Échelle de hauteur
   heightScale = max(0, 1 - scrollPercent * 1.5)
                 ↑ 1.5 = facteur d'accélération

// 3. Appliquer hauteur
   image.height = heightScale * 100 + '%'
   image.opacity = heightScale

// 4. Remonter contenu
   offsetY = min(scrollPercent * heroHeight * 0.5, heroHeight * 0.5)
   content.transform = translateY(-${offsetY}px)

6. OPTIMISATIONS CLÉS

✅ DO:
  • Use requestAnimationFrame (not setInterval)
  • Use will-change CSS property
  • Use backface-visibility: hidden
  • Add { passive: true } to scroll listener
  • Use transform: scaleY() over height changes
  • Disable on mobile
  • Test 60+ FPS

❌ DON'T:
  • Query DOM in RAF callback
  • Use setInterval for scroll
  • Ignore prefers-reduced-motion
  • Forget event listener cleanup
  • Use marginTop/paddingTop (reflows)

RÉSUMÉ FINAL

L'effet requiert 3 éléments:

1. IMAGE HERO
   Start: 100vh, Full opacity
   On Scroll: Height/Scale réduction progressif

2. CONTENT SECTION
   Start: Caché en bas
   On Scroll: Remonte via translateY

3. JAVASCRIPT
   Scroll Listener → RAF → Calculate % → Apply Transforms

Temps implémentation: ~30 min
Performance Impact: Minimal (2% CPU)
Browser Support: 99% modern browsers

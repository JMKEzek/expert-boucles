================================================================================
                        L'EFFET EN 30 SECONDES
================================================================================

MOUVEMENT PRINCIPAL:
  1. Image hero (100vh) se réduit graduellement à 0
  2. Contenu remonte de dessous pour remplir l'espace
  3. Synchronisation parfaite des deux mouvements

DÉCLENCHEUR:
  Scroll utilisateur (~300px déclenche l'effet complet)

TIMING:
  Frames 1-4:   Image FIXE (rien ne change)
  Frames 5-9:   Réduction progressive + contenu qui remonte
  Frames 10+:   Image disparue, contenu visible fullscreen

VITESSE:
  L'image disparaît 1.5x plus vite que le scroll
  (facteur d'accélération = 1.5)

================================================================================
                      FORMULES MAGIQUES À UTILISER
================================================================================

JavaScript:
  scrollPercent = scrollY / (heroHeight * 0.5)
  heightScale = max(0, 1 - scrollPercent * 1.5)
  image.height = heightScale * 100%
  content.transform = translateY(-scrollPercent * heroHeight * 0.5)

CSS (GPU optimisé):
  hero-image {
    will-change: height, opacity;
    backface-visibility: hidden;
  }
  content-section {
    will-change: transform;
  }
